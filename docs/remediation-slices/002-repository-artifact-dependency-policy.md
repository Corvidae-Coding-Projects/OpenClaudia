Status: Planned

Depends on: None

Canonical sources: [full audit](../full-codebase-audit-2026-08-16.md) and [remediation design](../production-remediation-design.md).

## Outcome

Make generated state, historical evidence, dependencies, and build artifacts follow an explicit source-control and retention policy.

## Implementation boundary

- Export and redact the historical Chainlink database/session evidence, then remove mutable databases, session markers, and generated bytecode from tracked source under an approved retention record.
- Add locked dependency/advisory/license/source checks, unmaintained-package replacement decisions, ignore rules, and bounded artifact cleanup guidance.
- Keep adjacent cleanup out of this change unless it is required to preserve compilation or the stated contract.

## Acceptance

- A clean checkout contains no mutable runtime database, active session marker, generated bytecode, or build output.
- CI reports locked dependency policy and the historical export can be verified by digest without exposing secrets.
- Relevant deterministic tests and trace assertions pass; attach an artifact-bound VDD receipt once S-088 is available.
